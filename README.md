# 📚 Book Inventory App

This project is part of the **freeCodeCamp** Responsive Web Design certification, focusing on structured HTML tables and advanced **CSS attribute selectors**.

---

## 🚀 Features & Implemented Requirements

* **Semantic Table Structure**: Uses `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>` elements to organize book details (`Title`, `Author`, `Category`, `Status`, and `Rate`).
* **Status & Rating Markup**: Uses `<span class="status">` elements inside rows classified with `read`, `to-read`, and `in-progress`, along with `<span class="rate ...">` containers wrapping three rating indicator `<span>` elements.
* **CSS Attribute Selectors & Gradients**: Targets specific elements and states using attribute selectors (`[class="..."]`, `[class^="rate"]`, `[class~="one"]`, `[class~="two"]`, `[class~="three"]`), `display: inline-block`, child/descendant combinators, `:first-child`, `:nth-child(-n+2)`, and `linear-gradient` backgrounds.
